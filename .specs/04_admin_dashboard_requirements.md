# 需求規格: Admin Dashboard (管理者主控台)

## 1. 背景 (Context)
Stock Souvenir 目前版本 v2.0.0 已成功遷移至 Supabase 架構。為了提升運營效率，急需一個整合式的後台管理介面，讓管理員能更有效地掌握用戶收藏數據，以及進行歷史資料的批次匯入，取代過往手動或分散的作業流程。

## 2. 目標 (Goals)
*   [ ] 提供管理員全域視角，查看並分析所有用戶的收藏行為。
*   [ ] 簡化歷史資料更新流程，支援 Excel/CSV 檔案直接匯入與自動除錯。
*   [ ] 打造符合 Pro Max UI/UX 標準的現代化後台介面。

## 3. 使用者故事 (User Stories)
*   **作為管理員**，我希望能查看所有用戶的收藏清單，以便了解哪些紀念品最受歡迎。
*   **作為管理員**，我希望能篩選特定股票或用戶的收藏紀錄，以進行精確的數據分析。
*   **作為管理員**，我希望能批次上傳 CSV/Excel 檔案來更新每年的紀念品資料，系統需自動判斷重複並更新 (Upsert)。
*   **作為管理員**，我希望在上傳失敗時能看到具體的錯誤行號與原因，以便快速修正檔案。

## 4. 功能需求 (Functional Requirements)

### 4.1 用戶收藏數據總覽 (User Favorites Overview)
*   **數據顯示**：
    *   列表欄位：用戶 Email、股票代碼、公司名稱、紀念品名稱、收藏日期、最後買進日。
    *   統計卡片：總用戶數、總收藏數、熱門紀念品 Top 5。
*   **篩選與搜尋**：
    *   依「用戶 Email」模糊搜尋。
    *   依「股票代碼」精確篩選。
    *   依「收藏日期」範圍篩選。
*   **資料導出**：支援將當前篩選結果匯出為 CSV。
*   **權限控制**：僅限 Role 為 `admin` 的用戶存取。

### 4.2 歷史資料批次匯入 (Bulk Data Import)
*   **檔案支援**：支援 `.csv`, `.xlsx`, `.xls` 格式。
*   **解析邏輯**：
    *   前端解析檔案內容。
    *   自動對應欄位：股票代碼、公司名稱、紀念品、最後買進日、開會日期、發放地點。
*   **寫入邏輯**：
    *   使用 Supabase Upsert，依據 `(stock_code, year)` 作為唯一鍵值判定重複。
*   **狀態回饋**：
    *   顯示上傳進度條。
    *   顯示成功/失敗筆數。
    *   若有錯誤，列出具體行號與錯誤原因 (如：格式錯誤、必填欄位缺失)。

## 5. 非功能需求 (Non-Functional Requirements)
*   **UI/UX**：
    *   遵循 Glassmorphism 設計風格 (半透明背景、模糊效果)。
    *   字體使用 Inter / Outfit。
    *   深色模式為預設主題。
    *   RWD 支援：手機版顯示為卡片列表，桌面版顯示為表格。
*   **效能**：
    *   收藏列表需支援分頁 (Pagination)，每頁 50 筆，避免一次載入過多數據。
    *   使用 Supabase View 優化跨表查詢效能。

## 6. 成功指標 (Success Metrics)
*   管理員能成功匯入含有 1000+ 筆資料的 Excel 檔案，且無誤判。
*   管理員能於 3 秒內篩選出特定股票的所有收藏紀錄。
