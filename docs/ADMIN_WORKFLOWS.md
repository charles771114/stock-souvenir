# 🛠️ 管理員進階操作手冊 (Admin Workflows)

本文件詳解管理員後台各模組的使用流程。

## 1. 庫存歸戶流程 (Inventory Staging Workflow)

這是管理大規模發放資料的核心流程，通常發生在領取季節結束或定期同步時。v3.2.0 起支援 PDF 自動解析與多帳戶歸戶。

### 第一步：檔案準備
- **PDF 通知書**：直接使用券商或集保的電子通知書 PDF。
- **Excel/CSV**：
    - 必備欄位：**證券代號**、**姓名/身分證號**、**年份**。
    - 可選欄位：**數量**、**類別**。

### 第二步：上傳與解析
- 前往「庫存歸戶管理」 -> 點擊「選擇檔案」或拖曳上傳。
- **PDF 模式**：系統會使用 `pdfjs-dist` 在前端自動OCR解析通知書內容，提取股東姓名、證券代號與股數。
- **Excel 模式**：依照欄位映射進行解析。

### 第三步：自動匹配 (Auto-Matching)
- **用戶匹配**：系統根據 `email` 或 `身分證號` (若有) 將資料對應到已註冊的用戶。
- **Portfolio 匹配**：若用戶有多個 Portfolio (如本人、配偶)，系統會嘗試根據姓名自動對應到正確的 Portfolio。
- **狀態燈號**：
    - 🟢 **完全匹配**：用戶與 Portfolio 皆確認，準備寫入。
    - 🟡 **部分匹配**：用戶確認但 Portfolio 不明，需手動選擇。
    - 🔴 **未匹配**：該用戶尚未登入過系統。

### 第四步：手動處理與確認
- 針對未匹配或部分匹配項目，點擊「分配」手動指定目標用戶與 Portfolio。
- 點擊「確認歸戶」。資料將從暫存區遷移至 `user_collections` 表（建立為 'holding' 狀態）。

## 2. 紀念品分類維護 (Classification Center)

為了讓用戶能方便篩選（例如只看「超商禮券」），管理員需維護分類邏輯。

### 手動分類
- 在「分類中心」查看「未分類」的紀念品項目。
- 使用下拉選單將其分配至正確類別（居家、食品、禮券等）。

### 關鍵字自動分類 (Keyword Mapping)
- 設定分類關鍵字。例如：關鍵字「商品卡」自動對應到「禮券」。
- 未來爬蟲抓取到包含該關鍵字的項目時，將自動完成歸戶。

---

## 3. 審核隊列 (Review Queue)

處理自動化過程中的存疑部分。

- **資料修正**：若抓取到的名稱包含錯字，可在此修正。
- **重複處理**：系統會標示可能的重複項目，管理員需決定保留或刪除。

---

## 4. 爬蟲管理 (Scraper Management)

- **新增來源**：設定目標網站的 URL 與 CSS Selector。
- **手動執行**：點擊「立即執行」觸發 Edge Function。
- **日誌查看**：檢查 `Scraper Logs` 確認是否有解析失敗的錯誤。
